# adiv — Jogo de Adivinhação

Jogo de adivinhar o número em **Python**, com três níveis de dificuldade.

## Dificuldades

| Nível | Intervalo | Tentativas |
|-------|-----------|------------|
| Fácil | 0–20 | 10 |
| Médio | 0–50 | 6 |
| Difícil | 0–100 | 4 |

O programa dá dicas (maior/menor) a cada erro.

## Como executar

```bash
python3 adiv.py
```
